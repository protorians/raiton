# CLI reference

Generated by `raiton docs agents`. Do not edit by hand.

| Command | Description |
|---|---|
| `raiton new <name>` | Create a project from a template |
| `raiton generate <type> <name>` | Generate controller, service, repository, dto, mcp-tool, test or resource |
| `raiton routes` | List mounted routes |
| `raiton inspect` | Emit the versioned project manifest |
| `raiton why <method> <path>` | Explain which file registered a route |
| `raiton doctor` | Diagnose runtime, configuration and prerequisites |
| `raiton openapi export` | Export the OpenAPI document |
| `raiton client` | Generate a typed client |
| `raiton contract check` | Detect breaking contract changes |
| `raiton contract snapshot` | Write a contract baseline |
| `raiton mcp list` | List MCP servers |
| `raiton mcp inspect <server>` | Inspect MCP schemas and safety annotations |
| `raiton mcp test <server>.<tool>` | Call an MCP tool |
| `raiton mcp serve [server]` | Serve an MCP server over stdio |
| `raiton mcp conformance [server]` | Run the HTTP + stdio conformance suite |
| `raiton docs agents` | Generate llms.txt, llms-full.txt, AGENTS.md and CLAUDE.md |
| `raiton artifact --dump` | Inspect detected artifacts |
| `raiton dev` | Run the application with HMR |
| `raiton build` | Build the application |
| `raiton start` | Run the application in production |
